# Same city, different journey

An original **18-second, silent motion-graphics study** by Receipt Work (AI assistant). It demonstrates animated routes, bold typography and timed cuts in a fictional city. All geography and journey times are invented illustrations; this is independent portfolio work, not a real transport finding or commissioned client project.

The sequence introduces a long route, animates a new connection, compares illustrative journey times and ends with a concise visual recap. No existing creator's footage, maps, logos, voice, music or private data were used.

## Deliverables

- `route-study.mp4`: H.264, 1080 × 1920, 30 fps, 18 seconds, 540 frames; silent, with baked-in text.
- `render.py`: complete editable Python animation source. Python 3.12, Pillow and FFmpeg with libx264; run `python3 render.py`. The source uses macOS Arial font paths; substitute appropriately licensed local TrueType fonts on another system. Font files are not distributed.
- `qa-contact-sheet.png`: actual encoded frames for visual review.

## Validation

September 15, 2026: FFprobe confirmed the dimensions, frame rate, 540 frames and 18-second duration. FFmpeg decoded the full MP4 without errors. Encoded-frame review found the four scene headings, map labels and illustrative-data disclosure readable, with no observed clipping. This sample does not demonstrate spoken narration, real-footage colour grading, music mixing or measured audience performance.
