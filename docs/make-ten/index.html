For grown-ups: guide, privacy and references

This original lesson is designed around age six, with an adult available to read or co-play. Start with counting objects one at a time. Reading, numeral recognition and experience vary; adjust the pace.

Allow about 8–12 minutes: a short demonstration, four quantity challenges, five make-ten pairs, six stories and a new two-step garden challenge. Pause or replay any activity.

Show the steps displays a strategy throughout. Let me explore keeps the same content and makes that strategy available through the Hint button. Either choice can be changed at any time.

Privacy: progress stays in this page's memory only. Refreshing or closing resets it. Start over clears all progress. No accounts, cookies, storage, analytics, chat, uploads or background network requests are used by the lesson. Optional read-aloud plays a bundled recording only when pressed. Press Stop reading to stop it. If audio cannot play, all instructions remain visible.

Original code, stories and CSS illustrations are offered under the MIT licence. Optional synthetic narration was generated locally from the original prompts with eSpeak NG; see audio provenance and audio permissions. System fonts are supplied by your device. No outside JavaScript dependencies.

Adult references: NCETM: Composition supports showing parts and wholes together. EEF: Use manipulatives and representations to develop understanding supports linking actions on objects to written numbers.

This app is a practice model, not a diagnosis or validated intervention. See the full educator guide, setup notes and the test report.
